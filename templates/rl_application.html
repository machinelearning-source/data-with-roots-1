The Application

Everything from RL Concepts is now running. The grid below is the environment; press [ Train Agent ] to run {{ episodes }} episodes of Q-Learning and see the policy it converges to.

  • Environment: 10×10 grid, 100 cells, 4 actions.
  • Algorithm: Q-Learning with SGDRegressor via partial_fit.
  • Policy: ε-greedy, decaying from {{ epsilon_start }} to {{ epsilon_min }}.
  • Seeded run, so the reported numbers are reproducible.
