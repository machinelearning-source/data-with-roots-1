Flight Segmentation

Scikit-Learn K-Means groups {{ n_records }} flight records by distance and duration, then evaluates the segmentation with silhouette analysis.

1. Problem context and justification

Why cluster flight operations?

The selected topic is flight segmentation by distance and duration. The application identifies natural operational segments without predefined labels, which can support route planning, aircraft utilization, and service-level analysis.

  • Records: {{ n_records }} synthetic but reproducible flight observations.
  • Feature 1: distance_km, measured in kilometers.
  • Feature 2: duration_min, measured in minutes.
  • Target: none for clustering. The optional delayed column is only used later for the supervised Logistic Regression exercise.

The data are appropriate for a reproducible academic demonstration because both clustering variables are numerical, the sample exceeds 1,000 records, and the records contain enough variation to reveal short-, medium-, and long-haul profiles.

2. Preprocessing

Steps applied before K-Means

  1. Read data/flights_dataset.csv with Pandas.
  2. Select only the numerical columns distance_km and duration_min.
  3. Validate that the required columns exist, contain numeric finite values, and provide at least 1,000 records.
  4. Apply StandardScaler so distance in kilometers and duration in minutes contribute comparably.
  5. Fit K-Means with K=3, init="k-means++", random_state=42, and n_init=10.
scaler = StandardScaler()
X_scaled = scaler.fit_transform(df[["distance_km", "duration_min"]])
model = KMeans(n_clusters=3, init="k-means++", random_state=42, n_init=10)
labels = model.fit_predict(X_scaled)
3. K-Means configuration

Why use three clusters?

K=3 is selected from the operational hypothesis of short-haul, medium-haul, and long-haul flight profiles. The candidate values below provide an internal comparison:
