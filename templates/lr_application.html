Estimate Delivery Time Based on Distance Traveled

Live practical implementation of a Simple Linear Regression model trained via Scikit-Learn across 600 urban logistics records.

# 1. Problem Context

Problem Context and Operational Motivation

What problem is being addressed?

In the courier, freight, and last-mile e-commerce logistics sector, accurately estimating door-to-door delivery duration is a critical operational bottleneck. Inaccurate arrival projections cause delivery bottlenecks, customer friction, driver idle time, and severe transport cost overruns.

Analyzed Phenomenon: The physical and operational relationship between the actual road transit distance (in kilometers) from fulfillment warehouses to destination addresses, and the total elapsed delivery time (in minutes) required to complete the delivery.

What do the data represent? The dataset represents 600 calibrated historical delivery shipments capturing baseline handling durations, real transit speeds, and urban traffic variance.

Purpose of applying Linear Regression: Mathematically model this relationship using Simple Linear Regression to empower logistics dispatchers with automated, instant, and reliable Estimated Time of Arrival (ETA) predictions for any new delivery distance.

# 2. Variable Identification

Model Variables and Units

X

Independent Variable (X)

Distance Traveled (distance_km)

The input feature provided by the user. Represents the transit route length from the distribution warehouse to the delivery doorstep.

  • Variable Type: Quantitative continuous
  • Unit of Measurement: Kilometers ($km$)
  • Role in the Model: Input Feature on the horizontal X-axis
  • Data Source: Fleet GPS onboard telematics logs
Y

Dependent Variable (Y)

Delivery Duration (delivery_time_min)

The target response variable predicted by the algorithm. Represents total door-to-door elapsed time.

  • Variable Type: Quantitative continuous
  • Unit of Measurement: Minutes ($min$)
  • Role in the Model: Output Target on the vertical Y-axis
  • Data Source: Enterprise TMS / ERP delivery completion timestamps
