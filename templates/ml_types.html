Taxonomy & Paradigms

Types of Machine Learning

A comprehensive taxonomy: Supervised, Unsupervised, and Reinforcement Learning paradigms.

Paradigm 1

Supervised Learning

Definition: In Supervised Learning, the algorithm is trained on a labeled dataset where each input feature vector is paired with an explicit, known target response (ground truth). The objective is to learn a mapping function capable of predicting the correct output for new, unseen inputs.

Main Characteristics:
  • Requires historical datasets with verified ground truth labels.
  • Evaluates model performance through explicit loss functions (e.g., Mean Squared Error, Cross-Entropy).
  • Follows a train-test split validation methodology to assess generalization.
Solvable Problem Categories:
Regression (Continuous Targets) Classification (Categorical Targets)
🎯
Core Algorithms

Linear Regression, Logistic Regression, Random Forest, Support Vector Machines (SVM), XGBoost.

Paradigm 2

Unsupervised Learning

Definition: In Unsupervised Learning, the algorithm processes unlabeled data without predefined output targets. Its goal is to uncover the inherent structure, groupings, or hidden probability distributions governing the input feature space.

Main Characteristics:
  • Operates without human annotations or pre-classified labels.
  • Driven by similarity metrics, distance functions (e.g., Euclidean), and density thresholds.
  • Essential for exploratory data analysis, market segmentation, and anomaly detection.
Solvable Problem Categories:
Clustering (K-Means, DBSCAN) Dimensionality Reduction (PCA, t-SNE) Anomaly Detection (Isolation Forest)
🔍
Core Algorithms

K-Means, Hierarchical Clustering, Principal Component Analysis (PCA), Autoencoders, Gaussian Mixtures.

Paradigm 3

Reinforcement Learning (RL)

Definition: Reinforcement Learning models an autonomous agent interacting with a dynamic environment through sequential trial and error. The agent perceives states, takes actions, and receives scalar feedback in the form of rewards or penalties, learning a policy that maximizes cumulative reward over time.

Main Characteristics:
  • No static labeled dataset; data is collected dynamically through environmental interaction.
  • Balances the exploration of unvisited states with the exploitation of known rewarding actions.
  • Deals with delayed rewards and long-term sequential planning.
Solvable Problem Categories:
Robotics & Autonomous Motion Strategic Game Playing (AlphaGo) Resource Allocation & Portfolio Management
🤖
Core Algorithms

Q-Learning, Deep Q-Networks (DQN), Proximal Policy Optimization (PPO), Actor-Critic (A2C).
