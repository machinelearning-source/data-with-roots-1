K-Means Clustering

Core concepts for discovering natural groups in flight records using distance and duration.

1. Unsupervised learning

Learning without labels

Unsupervised learning works with input features but without a target variable. The algorithm searches for structure that is useful for interpretation rather than trying to predict a supplied answer.

Input: feature matrix X
Output: groups or structure
Teacher: no labeled target
Task: clustering
Algorithm: K-Means
Validation: silhouette and WCSS
2. Clustering

Grouping similar observations

Clustering places observations in the same group when they are similar according to the selected features. In this project, the features are:

  • distance_km: how far the flight travels.
  • duration_min: how long the flight takes.

The expected segments are short-haul, medium-haul, and long-haul flight profiles. K-Means discovers these groups from the data without a cluster label.

3. K-Means algorithm

Centroids and iterative updates

  1. Choose the number of clusters, K, and initialize one centroid per cluster.
  2. Assign every observation to its nearest centroid using Euclidean distance.
  3. Update each centroid by averaging the coordinates of its assigned observations.
  4. Repeat the assignment and update steps until centroids stabilize or the iteration limit is reached.
d(p, c) = sqrt((x - cx)2 + (y - cy)2)

A centroid is a representative center, not a real flight. The application standardizes the two features before the Scikit-Learn run so their different units do not dominate the distance calculation.

5. Evaluation

Silhouette score

The silhouette score compares the distance of each observation to its own cluster with the distance to the nearest other cluster. Its approximate range is -1 to 1. Higher values indicate better separation, while values near zero indicate overlapping groups.

The score is calculated on standardized values because clustering distances are computed after preprocessing.
