1. Assigned model and target

Binary classification definition

The selected topic remains flight segmentation by distance and duration. The related binary target is defined as:

  • Model: Logistic Regression, the assigned classification model.
  • Target delayed: 0 = on-time flight and 1 = delayed flight.
  • Delay definition: the generated target applies a 15-minute threshold before converting the delay outcome to a binary class.
  • Input variables: distance_km and duration_min.
Specification note: the supplied rubric also mentions study_hours as an independent variable. The selected flight dataset does not contain a study-hours field, and study hours are not a valid operational predictor of flight delay. To avoid inventing data, this implementation uses the two numerical flight variables that are actually available.

Interpretation

The model estimates the probability that a flight exceeds the delay threshold. The threshold of 0.5 converts that probability into class 0 or class 1. Precision, recall, and F1 should be considered together because a false alarm and a missed delay have different operational costs.
