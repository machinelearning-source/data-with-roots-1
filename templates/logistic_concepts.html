Logistic Regression Concepts

Fundamental theory of binary classification: probability, thresholds and decision boundaries.

# 1. Core Concepts

Essential Theory

What is Logistic Regression?

Logistic Regression is a supervised learning algorithm used for classification. Although the word "regression" appears in its name, it does not predict continuous numbers. Instead, it models the probability that an observation belongs to one of two classes using the sigmoid (logistic) function:

p(class = 1) = 1 / (1 + e-(b0 + b1·X))

It then applies a decision threshold (typically 0.5) to convert that probability into a hard class.

Why is it a Classification Algorithm?

Its output is a probability bounded between 0 and 1 followed by a categorical decision (Class 0 or Class 1). Because the final prediction is a category (not a real number), Logistic Regression is formally a classification algorithm.

What is Binary Classification?

Binary classification is the task of assigning each observation to one of only two possible classes, for example 0 = No / 1 = Yes or 0 = Low Risk / 1 = High Risk. The target variable must contain exactly two distinct labels.

X

Independent Variable

The input feature used to make the prediction. In our project: time as a client in months (tenure_months).

Y

Dependent / Target Variable

The categorical outcome being predicted. In our project: churn with two possible classes: 0 = Stay and 1 = Churn.

Classes and Labels

The two categories the model distinguishes. Example used in this project: 0 = Stay (Cliente se queda) and 1 = Churn (Cliente se va). Positive class = 1, negative class = 0.

Probability and Threshold

The sigmoid returns P(class = 1). The classification threshold (usually 0.5) decides the class: if p ≥ 0.5 the observation is assigned to class 1; otherwise to class 0.
