Linear Regression - Concepts

Theoretical and mathematical foundations required to understand and implement Simple Linear Regression.

# Definition

What is Linear Regression?

Linear Regression is a foundational supervised learning algorithm that models the linear relationship between a quantitative independent explanatory variable (X) and a continuous dependent response variable (Y) by fitting an optimal straight line through observed data points.

Mathematical Formulation: Y = mX + b (or Y = β₀ + β₁X + ε)
Where m (or β₁) represents the slope coefficient, and b (or β₀) represents the y-intercept.

The goal is to calculate the optimal values of m and b that minimize the overall sum of squared residuals between observed values and model-predicted values.

# Applications

What Types of Problems Can It Solve?

Continuous Value Prediction

Forecasting numerical targets such as real estate sale prices, crop yields, salary scales, or delivery durations based on an input parameter.

Trend & Correlation Analysis

Quantifying the strength, slope, and statistical significance of an association: evaluating how strongly changes in X drive changes in Y.

Interpolation & Planning

Estimating expected values within the observed operational range to benchmark supply chain performance and optimize resource scheduling.

# Variables

Independent vs. Dependent Variables

X

Independent Variable (X)

The predictor, input feature, or explanatory factor. It represents the value fed into the model to generate an inference. Rendered along the horizontal axis (X-axis).

Logistics Example: Travel distance in kilometers (distance_km).

Y

Dependent Variable (Y)

The outcome, response variable, or prediction target. It represents the quantity the algorithm seeks to estimate. Rendered along the vertical axis (Y-axis).

Logistics Example: Delivery duration in minutes (delivery_time_min).

# Geometry & Optimization

The Regression Line and Ordinary Least Squares (OLS)

The regression line represents the best linear approximation of the empirical dataset. In a Cartesian scatter plot, each point corresponds to an individual observed record.

  • The line minimizes the Sum of Squared Errors (SSE), also known as the Mean Squared Error (MSE) objective function.
  • A positive slope (m > 0) indicates a direct relationship: as distance increases, delivery duration increases.
  • A negative slope (m < 0) indicates an inverse relationship.
Slope (m / β₁): Measures the marginal rate of change in Y for every unit increase in X (minutes per kilometer).
Intercept (b / β₀): Represents the expected baseline value of Y when X is zero (base loading/dispatch time).
# Numerical Example

Step-by-Step Predictive Walkthrough

Suppose our trained logistics model yields the fitted equation: Delivery Time (min) = 0.4482 · Distance (km) + 5.28

Sample Calculation: Trip of 50 km
  1. Input value: X = 50 km
  2. Apply slope: 0.4482 × 50 = 22.41 minutes of road transit.
  3. Add baseline intercept: 22.41 + 5.28 = 27.69 minutes total predicted delivery time.

This transparent mathematical clarity makes linear regression one of the most reliable, interpretable, and widely deployed models in applied data science.
